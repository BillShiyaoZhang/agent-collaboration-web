# 内容规范与人工处理

公开页面 `/community` 不需要登录，中英文正文在 `src/app/community/community-copy.ts`，复用网站语言切换、目录、窄屏样式和联系入口。内容审核页面应提供此规则的链接。规则允许正常工作沟通，并明确骚扰/歧视、性剥削/色情、暴力威胁、诈骗垃圾和未经许可个人资料等不可发布或批准的内容。

账户主人在网站审核具体对端记录与内容版本；批准只影响此账户显示，不是 AI 共享、业务执行或以后来信的许可。正文外发许可和 Agent 配对仍分别管理。真正阻止依赖 Agent 认证回执，不把账户列表隐藏当作远端阻止。未支持安全能力的旧 Agent 需升级。

举报先预览此记录的最小证据；只有用户选择才提交片段，正文默认不随报告发送。用户明确允许将报告交给当前工作区运营者，并在“我的举报”核实原 ID 和读取状态/回复。正式运营者应使用实际管理流程处理报告；页面不承诺未配置的自动分类或固定响应期限。
