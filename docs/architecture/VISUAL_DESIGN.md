# 公开页面与工作台的视觉约定

官网首屏围绕“让你的 agent，一起办事”组织成一个整体：中央可选取的大标题与接入入口，周边以真实 HTML 场景卡片说明同一件请求如何在 agent 之间传递。场景不是实时会话，也不表示消息送达会自动触发对方执行。接入步骤、能力范围和常见问题保留在下方；首页头部保持简洁，隐私与内容规范仍可从页脚进入。

官网使用浅暖灰、墨绿、衬线标题和有光泽的环形身份物件。工作台采用暖白纸面、清楚的双侧栏、墨绿选中项与浅绿主人消息；输入、授权、同步和业务状态仍由现有数据与组件决定。物件只作为缺省 agent 头像，不能覆盖用户实际身份信息。

## 实现入口

- [官网场景内容](../../src/components/public/home-content.ts)：中英文文案、语义化场景卡片和实际导航。
- [官网场景样式](../../src/components/public/hero-scene.css)：桌面整体构图、窄屏与大字号回流、减少动画和强制颜色适配。
- [公共导航](../../src/components/public/public-navigation.tsx)：首页简洁导航与所有公开页的完整页脚。
- [工作台基础样式](../../src/app/globals.css)：`dashboard-shell` 范围的视觉规则，不改变协议或授权。
- [绿色物件](../../public/brand/agent-loop-sage.png)和[淡紫物件](../../public/brand/agent-loop-lilac.png)：2026-09-27 通过内置 image_gen 生成的原创透明 PNG；[完整生成提示词](../../public/brand/asset-prompts.json)随源码保存。它们不是 Wabi 网站的素材。

图片只有装饰作用，使用空 `alt`，可访问名称来自旁边的文字。标题、按钮和状态不能烘焙进图片；图片失败时内容与操作仍可读。静态 PNG 随 Web 镜像发布，不依赖第三方图片地址。

## 验证

运行 Web 单元检查与生产构建，再按[测试指南](../../tests/README.md)验证中英文、320px、200% 字号、键盘跳转、接入 CTA、内容共享、聊天和账户隔离。窄屏和文字放大时，周边场景卡片进入正常文档流；业务 UI 不使用倾斜窗口或漂浮效果。生产发布时间与实际验收属于部署仓库的当次发布记录。
